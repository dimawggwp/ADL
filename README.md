# ADL — сайт корпусной мебели (Алматы)

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | Главная: бесконечная галерея, 3D-примерка, конфигуратор (без цен), сроки (14 дней после замера), гарантия 5 лет, FAQ, заявка |
| `constructor.html` | 3D-примерка: фото → автопоиск углов стены → мебель вписывается от угла до угла → отправка проекта |
| `assets/js/wall-fit.js` | Поиск углов стены на фото и точный расчёт камеры по 4 точкам (работает без ИИ и сервера) |
| `admin.html` | Админ-панель: загрузка работ в галерею + все заявки с сайта |
| `assets/js/config.js` | Телефон, опции конфигуратора, настройки — меняйте здесь |
| `supabase/schema.sql` | База данных (выполнить один раз) |

---

## Шаг 1. База данных Supabase (5 минут)

1. Откройте supabase.com → ваш проект → **SQL Editor** → **New query**.
2. Скопируйте весь файл `supabase/schema.sql`, вставьте и нажмите **Run**.
   (Хранилища фото `gallery` и `projects` уже созданы.)
3. **Authentication → Users → Add user → Create new user**: ваш email и пароль (поставьте галочку *Auto Confirm User*).
4. Снова в SQL Editor выполните, подставив свой email:
   ```sql
   insert into public.admins (email) values ('ВАШ_EMAIL@gmail.com');
   ```
5. Рекомендуется: **Authentication → Sign In / Providers → Email** → выключить *Allow new users to sign up*, чтобы посторонние не регистрировались.

## Шаг 2. Публикация на GitHub Pages

Вся папка `ADL` — это и есть сайт и git-репозиторий (отдельная «плоская» сборка больше не нужна).

1. github.com → **New repository** → имя, например `adl-mebel` → Public → Create (без README).
2. В Терминале:
   ```bash
   cd ~/Desktop/ADL
   git remote add origin https://github.com/ВАШ-ЛОГИН/adl-mebel.git
   git push -u origin main
   ```
3. **Settings → Pages → Branch: main / root → Save**.
4. Через 1–2 минуты сайт будет по адресу `https://ВАШ-ЛОГИН.github.io/adl-mebel/`. Админка: `.../admin.html`.
5. Дальше любые правки: `git add -A && git commit -m "что изменили" && git push`.

## Шаг 3. Заявки в WhatsApp

Сейчас: клиент нажимает «Отправить» → заявка сохраняется в базе (видна в админке) **и** у клиента открывается WhatsApp с готовым текстом на номер 8 707 604 19 86 — ему остаётся нажать «Отправить».

**Полностью автоматически (оператору приходит сообщение без участия клиента)** — бесплатно через CallMeBot:
1. С телефона, где WhatsApp 8 707 604 19 86, добавьте в контакты номер бота CallMeBot (актуальный номер — на сайте callmebot.com → WhatsApp API) и отправьте ему: `I allow callmebot to send me messages`.
2. Бот пришлёт **apikey**.
3. В Supabase SQL Editor:
   ```sql
   insert into public.app_settings (key, value) values
     ('callmebot_phone', '77076041986'),
     ('callmebot_apikey', 'ВАШ_КЛЮЧ')
   on conflict (key) do update set value = excluded.value;
   ```
4. Готово: каждая заявка сразу приходит в WhatsApp (имя, телефон, что заказывают, расчёт, ссылка на 3D-проект).
5. Если хотите, чтобы у клиента больше не открывался WhatsApp — в `assets/js/config.js` поставьте `openWhatsAppAfterLead: false`.

## Шаг 4. Конфигуратор и галерея

- Конфигуратор на сайте **не показывает суммы**: клиент собирает мебель (тип, размеры, корпус, фасады, столешница, фурнитура, LED, ящики и т.д.), видит «класс проекта» (Стандарт / Комфорт / Премиум), и заявка с полной конфигурацией уходит менеджеру. Смету называет менеджер — с учётом всех расходов.
- Опции и границы классов — в `assets/js/config.js` → `CALC`.
- 3D-конструктор тоже без цен: клиент отправляет проект со снимком, менеджер считает.
- **Галерея:** работы добавляются, меняются и удаляются в `admin.html`. Если вы вошли в админку, то и на самом сайте у каждой работы появляется кнопка «Удалить» (и в окне работы — «Удалить из галереи»). Посетители этих кнопок не видят.

## Разметка стены по 4 углам (работает сразу, без настройки)

После фото программа сама находит линию пола, потолка и углы стены и предлагает 4 точки. Клиент проверяет их (при перетаскивании появляется лупа, точки «примагничиваются» к углам), может ввести высоту потолка или ширину стены по рулетке — тогда размеры точны до сантиметра. По 4 точкам рассчитывается камера, и мебель вписывается от угла до угла. Сверху появляется быстрый выбор: шкаф, купе, кухня, ТВ-зона, комод.

## ИИ-разметка комнаты (Gemini) — необязательно

Без ИИ всё работает. С ИИ разметка полностью автоматическая: ИИ уточняет углы, находит окна, двери, радиаторы, плинтус и свет, переставляет мебель так, чтобы не закрывать радиатор и дверь, и **убирает с фото мусор и временные предметы** (коробки, пакеты, старую мебель) — у клиента остаётся кнопка «Показать фото как было».

Модели можно сменить секретами `GEMINI_MODELS` (анализ) и `GEMINI_IMAGE_MODELS` (очистка фото).

После загрузки фото в 3D-примерке ИИ сам находит углы, линию пола и потолка, плинтус, окна, двери, радиаторы, розетки и источник света. Конструктор по этим данным калибрует камеру, отодвигает мебель на толщину плинтуса, не ставит её на дверь/радиатор, а кнопка «Вписать в нишу» подгоняет ширину и высоту под свободное место.

Ключ Gemini хранится только на сервере Supabase, на сайте его нет. Подключение (один раз, ~3 минуты):

1. Supabase → **Edge Functions** → **Deploy a new function** → **Via Editor**.
2. Имя функции: `room-ai` (именно так).
3. Удалите пример кода и вставьте целиком файл `supabase/functions/room-ai/index.ts` → **Deploy function**.
4. Edge Functions → **Secrets** → **Add new secret**: Name `GEMINI_API_KEY`, Value — ваш ключ Gemini → Save.
5. Готово. Проверьте: загрузите фото в 3D-примерке — появится полоса сканирования и блок «ИИ разметил комнату».

Необязательно: секрет `ALLOWED_ORIGINS` = адрес вашего сайта (например `https://логин.github.io`), чтобы функцию нельзя было вызывать с чужих сайтов.

## Шаг 5. Чтобы сайт находили по «мебель алматы», «корпусная мебель алматы»

На сайте уже есть: заголовки и тексты с ключевыми словами, meta description/keywords, разметка Schema.org (мебельный магазин в Алматы + FAQ), sitemap и robots.txt.
Чтобы выйти в топ, нужно ещё (это не делается кодом):
1. **Свой домен** (например `adl-mebel.kz`, ~5 000 ₸/год) → GitHub Settings → Pages → Custom domain. Замените `ВАШ-ДОМЕН` в `sitemap.xml` и `robots.txt`.
2. **Google Search Console** и **Яндекс Вебмастер** — добавить сайт и отправить `sitemap.xml`.
3. **Google Business Profile**, **2GIS**, **Яндекс Бизнес** — карточка «Корпусная мебель на заказ, Алматы» с телефоном, фото работ и ссылкой на сайт. Для локального поиска это даёт больше всего.
4. Регулярно добавляйте работы в галерею и просите клиентов оставлять отзывы в 2GIS/Google.

Первые позиции обычно появляются через 2–8 недель после индексации.

## Безопасность

- На сайте используется только **публичный (anon) ключ** — это нормально, данные защищены правилами доступа (RLS): посетители могут только отправлять заявки и смотреть галерею.
- **Secret / service_role ключ нигде на сайте нет и никогда не должен там быть.** Так как он был отправлен в чат, рекомендуем перевыпустить его: Supabase → Project Settings → API Keys → Roll / создать новый secret key.
